# Sikkerhedspolitik / Security policy

## Understøttede versioner

Kun den aktuelle `master`-gren vedligeholdes. Der er ingen versionerede releases.

## Rapportering af en sårbarhed

Opret ikke et offentligt issue om sikkerhedsproblemer.

Brug GitHubs private sårbarhedsrapportering på dette repository
(**Security → Report a vulnerability**), eller kontakt vedligeholderen via
GitHub-profilen [@saabendtsen](https://github.com/saabendtsen). Du kan forvente
et første svar inden for 14 dage. Beskriv venligst hvordan problemet
reproduceres, og hvilken commit eller udrulning du testede mod.

Applikationen er et privat husholdningsbudget, der køres selv-hostet; rettelser
laves efter bedste evne, og der er ingen bug bounty.

---

*English:* Please report vulnerabilities privately via GitHub's private
vulnerability reporting on this repository or through
[@saabendtsen](https://github.com/saabendtsen); first response within 14 days,
best-effort fixes, no bug bounty.
